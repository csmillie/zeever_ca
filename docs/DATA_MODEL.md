# Data Model

**Status:** Draft

This document provides comprehensive documentation of the database schema for the Canadian AI system, including all tables within the canadian_ai schema such as crawl_runs for tracking crawl operations, raw_documents for original content, parsed_documents for structured extraction, document_chunks for semantic segmentation, graph_nodes and graph_edges for the knowledge graph, workflows for permit processes, and eval_prompts and eval_results for system evaluation. The schema design is defined in db/migrations/001_initial_schema.sql which serves as the source of truth for all table definitions, relationships, and constraints.
