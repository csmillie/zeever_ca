# Graph Scope

**Status:** Draft

This document defines the scope and design of the GraphRAG knowledge graph, which is limited to the building permits corpus from Toronto.ca. It specifies the entity types to be extracted including permit_type, document, step, requirement, fee, and inspection, the relationship types that connect entities such as requires, followed_by, costs, and inspected_by, and the workflow extraction goals that aim to construct executable sequences of permit application steps and decision trees.
