# Crawl Policy

**Status:** Draft

This document specifies the web crawling policies and constraints for the building permits assistant, including the scope limited to Toronto.ca building permits pages only, rate limiting of 1 second between requests to be respectful of server resources, user agent configuration, compliance with robots.txt directives, sitemap-based discovery strategy, and URL filtering rules that determine which pages are included or excluded from the crawl.
